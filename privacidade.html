Política de Privacidade

Assistente UCL. Atualizada em 1 de novembro de 2026.

Quais dados o app acessa

Com a autorização do usuário, o app acessa o endereço de e-mail da conta Google e, somente para leitura, os arquivos do Google Drive que essa conta consegue abrir. Um arquivo ou pasta só é acessado quando o usuário pede aquele material.

Como os dados são usados

Os dados servem apenas para baixar e ler os materiais solicitados pelo usuário. O app não usa esses dados para publicidade e não os vende.

Onde os dados ficam

O app roda no computador do próprio usuário. O token de acesso fica nesse computador, criptografado com a proteção do Windows (DPAPI), e os arquivos baixados ficam em uma pasta local. O projeto não mantém servidor próprio que guarde esses dados.

Com quem os dados são compartilhados

O texto de um material é enviado ao assistente de IA que o usuário escolheu (Claude, da Anthropic) quando o usuário pede para ler ou resumir aquele material. Esse envio segue os termos do serviço do assistente. O projeto não compartilha os dados com mais ninguém.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar e apagar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Para apagar os dados locais, basta remover a pasta .ucl do perfil de usuário no Windows.
